# Harbuz - browser for Lilka

## Features
- navigating HTML pages
- background JPEG and PNG download
- cookies support
- saving files to SD card
- navigation history + favorites


## Limitations
- JS, CSS, SVG, etc. are not supported
- Google search doesn't work (JS)
- sites behind bot protection might not load
- Lilka catalog doesn't work (JS)


## What works
- duckduckgo or startpage.com search
- Downloading files from github
- Wikipedia, news sites
