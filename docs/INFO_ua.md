# Гарбуз - браузер для Лілки

## Функції
- навігація HTML-сторінок
- фонове завантаження зображень JPEG та PNG
- підтримка cookies
- завантаження файлів на SD-карту
- історія та вподобані сторінки


## Обмеження
- нема підтримки JS, CSS, SVG і т.п.
- не працює пошук Google (JS)
- можуть не працювати сайти з захистом від ботів
- не працює Лілка Каталог (JS)


## Працюють
- пошук через duckduckgo або startpage.com
- навігація та завантаження BIN-файлів прямо з github
- вікіпедія, сайти новин
